Detailed Description

Functions in this class deal with getting and setting trigger action parameters for the PCIe.

Note
Can either be created by passing a Device instance to TriggerFactory::CreateTriggerActionManager() or by instantiating directly with a STAR-System device ID.
Examples:
triggering_example.cpp.
