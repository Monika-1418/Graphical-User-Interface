◆ IsAutoStart()

char IsAutoStart ( )
inline

Get whether the SpaceWire link will auto start.

As defined in the SpaceWire standard, the SpaceWire port will wait until the other end of the link tries to make a connection (sending NULLs) and will then automatically start.

Returns
1 if auto start is on, otherwise 0.
Examples:
device_config_tester.cpp.
