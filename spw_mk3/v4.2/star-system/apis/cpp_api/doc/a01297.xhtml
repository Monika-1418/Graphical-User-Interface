◆ GetDeviceListForDriver()

Device** GetDeviceListForDriver ( _Out_ U32 *  count)
inline

Gets an array of devices present for this driver.

Parameters
[out]countNumber of devices returned in the array.
Returns
An array of pointers to Device objects representing all of the devices found for the driver, or NULL if no devices are found.
Note
This function returns a snapshot of the current state of the the system and is not automatically updated.
This array and its contents must be freed when no longer required using the C++ delete operator or the STARSystem::DestroyDeviceList() function.
Examples:
star_test.cpp.
