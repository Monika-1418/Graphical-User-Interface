Detailed Description

Parent class for objects which are used to identify listeners or call-back objects which have been registered to receive notifications of STAR-System events, e.g.

devices added or removed, channels opened or closed, etc, and which must subsequently be unregistered when notifications are no longer required.

◆ Unregister()

virtual int Unregister ( )
pure virtual

Unregister the listener and the Call-back object that was previously registered to be called whenever an event of interest occurred, e.g.

a device added or removed, a channel opened or closed, etc.

Returns
1 if listener unregistered successfully, otherwise 0.
Note
This is a pure virtual function. Derived classes within the API which represent more specific forms of listener will override this to provide the necessary unregistration logic.
