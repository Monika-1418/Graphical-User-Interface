Detailed Description

Holds information for a link speed event.

Note
If a LinkSpeedEvent originates from a ReceiveOperation (e.g. GetTransferItem() or GetTransferItemList()) then the contained data may be disposed of by the underlying C API or when the ReceiveOperation is destroyed. If the received data is being queued for later processing then it is recommended to queue the contained data rather than the LinkSpeedEvent.
Examples:
device_config_tester.cpp, and link_events.cpp.
