Detailed Description

Functions in this class deal with the manual RMAP target authorisation on a PXI card.

Note
Can either be created by passing a Device instance to RMAPTargetFactory::CreateRMAPTargetManualAuthorisationManager() or by instantiating directly with a STAR-System device ID.
Examples:
rmap_target_example.cpp.
