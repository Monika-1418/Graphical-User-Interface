Detailed Description

Represents a SpaceWire time-code which is to be transmitted (or has been received) over a SpaceWire link.

Note
If a TimeCode originates from a ReceiveOperation (e.g. GetTransferItem() or GetTransferItemList()) then the contained data may be disposed of by the underlying C API or when the ReceiveOperation is destroyed. If the received data is being queued for later processing then it is recommended to queue the contained data rather than the TimeCode.
Examples:
time_code_example.cpp.
