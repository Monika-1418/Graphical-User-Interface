Detailed Description

An address is used to route a packet through a SpaceWire network from a source node to a destination using the two main forms of addressing defined in the SpaceWire standard: path addressing and logical addressing.

Examples:
device_config_tester.cpp, link_events.cpp, listener_examples.cpp, rmap_examples.cpp, rmap_initiator_example.cpp, rmap_target_example.cpp, timestamp_test.cpp, and transmit_and_receive_example.cpp.
