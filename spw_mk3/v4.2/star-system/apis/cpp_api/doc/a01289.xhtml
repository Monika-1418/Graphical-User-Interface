Detailed Description

Identifies a listener or call-back object which has been registered to receive notifications of device-related events, e.g.

devices added or removed, and which must subsequently be unregistered when device notifications are no longer required.

Examples:
listener_examples.cpp.

Copy constructor - to allow copies of DeviceListener objects to be made when being passed by value in functions or returned by value from functions.

When a copy of an existing DeviceListener is made, the copy shares a reference to the existing DeviceListener. This is rather than registering a new DeviceListener which is a duplicate of that being copied. A reference counting mechanism is employed to manage shared references to a device listener.

◆ operator=()

DeviceListener& operator= ( const DeviceListener &  listenerBeingAssignedFrom)
inline

Overloaded assignment operator - to allow instances of DeviceListener objects to have their contents assigned to each other.

When the contents of one DeviceListener object are assigned to another, they will both share a reference to the same underlying device listener. This is rather than a duplicate being made, which would involve registering an entirely new DeviceListener. Any existing listener which is currently held will be removed and unregistered if required (if there are no other references held to it shared amongst other objects) before assigning the new listener to it. A reference counting mechanism is employed to manage shared references to a device listener.
