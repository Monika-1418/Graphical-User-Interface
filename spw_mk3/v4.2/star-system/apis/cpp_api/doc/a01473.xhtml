Detailed Description

Functions in this class deal with the RMAP target notification handling on a PXI card.

Note
Can either be created by passing a Device instance to RMAPTargetFactory::CreateRMAPTargetNotificationManager() or by instantiating directly with a STAR-System device ID.
Examples:
rmap_target_example.cpp.
