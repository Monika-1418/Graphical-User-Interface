retrieving the list of devices which are present and the versions of API modules.

int  notifyForCurrent 
)
inlinestatic

Registers a Call-back object that will receive notifications of whenever any channel is opened or closed.

Parameters
pCallBackObjA pointer to a user-supplied object which will be registered to receive notifications of any channels being opened or closed.
notifyForCurrentSpecifies whether notifications should be provided for all existing channels, to indicate that they have been opened.
Returns
A pointer to a new ChannelListener object which identifies the listener registered and can be used to unregister the listener when it is no longer required, OR NULL if failed to register the listener or if a memory allocation failure occurred.
Note
A ChannelListener must be unregistered when no longer required. This can be performed when required by calling the Unregister() function on the ChannelListener. Alternatively, the ChannelListener will be automatically unregistered if it hasn't been already when the object goes out of scope or is deleted, i.e. in the object destructor.
The ChannelListener object returned must be freed when no longer required by calling the C++ delete operator.
Examples:
listener_examples.cpp.
