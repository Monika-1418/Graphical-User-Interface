Detailed Description

Functions in this class deal with getting and setting trigger configuration parameters on the PXI interface.

Note
Can either be created by passing a Device instance to TriggerFactory::CreateTriggerConfiguration() or by instantiating directly with a STAR-System device ID.
Examples:
triggering_example.cpp.
