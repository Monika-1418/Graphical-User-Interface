Detailed Description

Base class for stream items.

Stream items are abstract representations of the data which are typically transmitted and received over a SpaceWire link, e.g. packets, time-codes, link control tokens.

Note
If a StreamItem originates from a ReceiveOperation (e.g. GetTransferItem() or GetTransferItemList()) then the contained data may be disposed of by the underlying C API or when the ReceiveOperation is destroyed. If the received data is being queued for later processing then it is recommended to queue the contained data rather than the StreamItem.
Examples:
device_config_tester.cpp, link_events.cpp, listener_examples.cpp, rmap_examples.cpp, rmap_initiator_example.cpp, rmap_target_example.cpp, time_code_example.cpp, timestamp_test.cpp, and transmit_and_receive_example.cpp.
