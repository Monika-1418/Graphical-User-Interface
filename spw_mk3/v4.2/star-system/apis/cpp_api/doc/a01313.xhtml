Detailed Description

An error in data instance is used to indicate an error to be injected into packet data and cause an error to occur on the following data character.

Note
If a ErrorInData originates from a ReceiveOperation (e.g. GetTransferItem() or GetTransferItemList()) then the contained data may be disposed of by the underlying C API or when the ReceiveOperation is destroyed. If the received data is being queued for later processing then it is recommended to queue the contained data rather than the ErrorInData.
