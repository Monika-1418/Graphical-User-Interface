Detailed Description

Represents a chunk of contiguous SpaceWire data, within a single packet.

Note
If a DataChunk originates from a ReceiveOperation (e.g. GetTransferItem() or GetTransferItemList()) then the contained data may be disposed of by the underlying C API or when the ReceiveOperation is destroyed. If the received data is being queued for later processing then it is recommended to queue the contained data rather than the DataChunk.

Parameters
[in]streamItemThe stream item to initialize the object with.
[in]shouldBeDestroyedWhether or not the underlying stream item should be destroyed when the data chunk is freed.
Note
Because a pointer to an already existing stream item is provided, the memory associated with the stream item will not be automatically freed by this object when it goes out of scope or is destroyed. Only the pointer reference will be removed.
