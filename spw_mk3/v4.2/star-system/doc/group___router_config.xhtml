Detailed Description

The Router Configuration API provides functions for configuring features common to a number of SpaceWire routing devices.

The devices directly supported by the Router Configuration API include the SpaceWire PCI Mk2 and cPCI Mk2, the SpaceWire PCIe, the SpaceWire Brick Mk2, the SpaceWire Router Mk2S, the SpaceWire Brick Mk3, the SpaceWire Router-USB, the SpaceWire Router Mk2, the SpaceWire-USB Brick and the ESA SpW-10X.
